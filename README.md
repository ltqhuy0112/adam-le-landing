# Adam Le — Portfolio Landing Page

Animated, bilingual (English/Vietnamese) portfolio for Adam Le, built as a static website.

## Run locally

Open `index.html` in a browser, or serve this directory with any static file server. There are no build steps or dependencies.

## Deploy

Upload the contents of this repository to a static hosting service such as Netlify or Cloudflare Pages. The publish directory is the repository root (`.`).

## Files

- `index.html` — page structure and content
- `styles.css` — responsive layout and animation
- `app.js` — language switcher, navigation, and UI interactions
- `assets/` — portrait, favicon, and social preview image
